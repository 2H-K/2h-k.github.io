## 2. 知识框架

  IP 定终点，MAC 定下一跳

## 3. 简答与名词解释

### 必背

- **逐跳转发字段变化规律**：主机发出的帧：源 IP=本机、目的 IP=终点（端到端不变），源 MAC=本机网卡、目的 MAC=**下一跳**（网关或同网目的主机）。每经过一台**路由器**：TTL 减 1、重算首部校验和、**帧头整体重写**（源 MAC=路由器出接口、目的 MAC=新下一跳）；IP 头中源/目的地址**不变**。经过**交换机/集线器**：二层设备，帧内容不改变（交换机做自学习/过滤转发）。
- **ARP 与"下一跳"的关系**：发送前先判定"下一跳"是谁——同网就是目的主机，异网就是默认网关；然后对**下一跳的 IP** 做 ARP 得到其 MAC 填入帧头。广播帧（ARP 请求）不能穿越路由器，因此 ARP 解析永远只发生在本网段。
- **集线器 vs 交换机 vs 路由器**：集线器工作在物理层，比特广播式转发，**不隔离冲突域、不隔离广播域**；交换机工作在链路层，按 MAC 表转发，**隔离冲突域、不隔离广播域**（VLAN 除外）；路由器工作在网络层，按 IP 转发，**既隔离冲突域又隔离广播域**。
- **交换机自学习**：收到帧时把"源 MAC + 进入端口"登记进 MAC 地址表；查目的 MAC：表中有 → 从对应端口转发（同端口则过滤）；表中无 → **向除入口外所有端口泛洪**。MAC 表项有老化时间。由此推出考点：广播帧永远泛洪；单播首次通信必泛洪一次。

### 辨析

- **默认网关 vs DNS 服务器**：网关是"异网数据先交给谁"（三层转发，每台主机必配）；DNS 服务器是"域名翻译成 IP 问谁"（应用层服务，联动 02 篇）。主机配网：IP + 掩码 + 网关 + DNS，四件套各司其职。
- **DHCP 跨网段 vs ARP 跨网段**：DHCP 客户端请求是广播，跨网段靠**中继代理**（单播转给远端服务器，02 篇）；ARP 广播**不能**跨网段，跨网段解析的是网关。两者都涉及"广播出不了路由器"，一个靠中继、一个靠网关解析。
- **同网直接交付 vs 异网间接交付**：判定只看一步——目的 IP & 本机掩码 == 本机网络地址？相同 → 直接交付（ARP 目的主机）；不同 → 间接交付（ARP 网关）。所有逐跳题的第一步都是这个判断。
- **路由器收到目的为本网广播的帧**：不转发（隔离广播域）；但**目的 IP 是直接广播地址**（主机号全 1）且来自别的网时，在本网内作为广播发出（联动 11 篇特殊地址表）——选择题爱混这两句。

### 了解

- 静态路由 vs 默认路由 0.0.0.0/0（最长前缀匹配兜底，11 篇）
- NAT 出口改写源 IP+端口（私有地址考点，11 篇；综合题若标明 NAT 需改写 IP）。逐跳过程中要分清两种设备的改写：普通路由器只做二层的事，换源 MAC 和目的 MAC、TTL 减 1、重算首部校验和，源 IP 与目的 IP 全程不动；只有内网到公网边界上的 NAT 路由器在普通转发动作之外再做一次地址转换——内网主机第一次向外网发包经过它时，把源 IP 从私有地址换成公网 IP、源端口换成临时端口并记入转换表；回程报文到达时，再把目的 IP 和目的端口按表换回私有主机。所以综合题的逐跳字段表里，MAC 列逢路由器就换，IP 列只有标明 NAT 的那一段才变，且出站改的是源、回程改的是目的。两条易漏的连带动作：①NAT 改完 IP 和端口后**传输层校验和也必须重算**——TCP/UDP 校验和覆盖的伪首部包含 IP 地址，地址一变旧校验和必失效（UDP 校验和置 0 表示不校验时除外）；②普通路由器若出接口 MTU 装不下整个数据报，还要**就地分片**：为每片重填总长度、MF 与片偏移，并**逐片重算首部校验和**（每片首部已不同）。
- traceroute 在拓扑题里的应用：TTL 逐跳暴露路由器地址（12 篇）

## 4. 易混对比表

| 设备 | 工作层次 | 转发依据 | 隔离冲突域 | 隔离广播域 | 是否改写帧 | 即插即用 |
|---|---|---|---|---|---|---|
| 集线器 | 物理层 | 无（广播比特） | 否 | 否 | — | ✓ |
| 交换机 | 链路层 | MAC 地址表 | **是** | 否（VLAN 可） | 否（透明） | ✓（自学习建表） |
| 路由器 | 网络层 | 路由表（IP） | 是 | **是** | **是**（重写帧头+TTL−1） | ✗（需配接口 IP 与路由表） |

| 场景 | 源 IP | 目的 IP | 源 MAC | 目的 MAC |
|---|---|---|---|---|
| 同网 A→B | A | B | A | B |
| 异网 A→网关（第一段） | A | B | A | 网关入接口 MAC |
| 网关→B（最后一段） | A | B | 网关出接口 MAC | B |
| 中间路由器段 | A | B | 上游接口 MAC | 下游接口 MAC |

> 记法：IP 列从头到尾"**A、B 原地不动**"；MAC 列"**段段刷新**"。填表题先填 IP 列（全不变），再逐段填 MAC（看下一跳）。

| 广播/泛洪行为 | 传播范围 | 例 |
|---|---|---|
| MAC 广播（FF…FF） | 本冲突域内所有端口（交换机泛洪、路由器截断） | ARP 请求 |
| IP 受限广播 255.255.255.255 | 本网络（路由器不转发） | DHCP DISCOVER |
| IP 直接广播（主机号全 1） | 目标网络内广播 | 跨网通知某网全体主机 |

## 5. 计算与方法

![综合拓扑总题图：六个子网 A–F、四台路由器、防火墙与服务器](/assets/img/csreview/net-topology-full.png)
_全篇自编题共用此图。读图先抓三点：①子网 A 标注掩码 255.255.240.0（/20），网络地址是 222.118.**32**.0，别被主机地址 222.118.44.x 带偏；②子网 B 是 172.18.32.0/**26**（掩码 255.255.255.192）且为**私有地址**块，出网必经 NAT；③接口 MAC 编号有规律——字母位对应所在子网（A 网主机 MAC 以 2 开头、R1 靠 F 侧接口是 1D…），数字位对应该网段内的主机号/接口号，做题时直接按图取值_

### ① 端到端发送全流程（大题总纲）

**触发条件**：拓扑 + 地址表，"主机 A 第一次与 B 通信，简述全过程"。

**步骤模板（背顺序）**：
1. **应用层**：若有域名先问 DNS（02 篇）；组装报文（HTTP/02 篇）
2. **传输层**：选 TCP（三次握手 08 篇）或 UDP；确定端口，封装段
3. **网络层**：掩码判断同/异网（11 篇）→ 定下一跳；若总长超 MTU 先分片（12 篇）；TTL 初值、协议字段填好
4. **链路层**：查 ARP 缓存→未命中广播请求→得下一跳 MAC（12 篇）；封装帧
5. **每台路由器**：查路由表最长前缀匹配（11 篇）→ TTL−1 重写帧头 → 下一跳再 ARP
6. **目的主机**：收帧→重组分片（若分片）→ 交传输层按端口分用（06 篇）→ 应用进程处理

### ② 逐跳填表题（本篇压轴模板）

**触发条件**：给出拓扑（如总题图中 A —S2— R2 —S1— R4 —S4— G 这类多段以太网路径），要求填经过各设备后帧中字段。

**步骤**：
1. 列字段四列：源 IP、目的 IP、源 MAC、目的 MAC
2. IP 两列全段不变，直接填源/目的主机地址
3. MAC 按段写：源主机→R2 段（源主机，R2 入口）、R2→R4 段（R2 出口，R4 入口）、R4→目的主机段（R4 出口，目的主机）
4. 经过交换机行：四个字段全"不变"，另注"交换机自学习源 MAC"
5. 每过路由器行：另注"TTL−1、重算校验和"

**自编例题**（用总题图）：主机 A（222.118.44.2，MAC 2A-…-2A，子网 A /20）→ 主机 G（154.121.30.2，MAC 2B-…-2B，子网 C /24），路径 A —S2— R2 —S1— R4 —S4— G，跨 3 段以太网、2 台路由器。逐段填表（MAC 用图中接口值缩写）：

| 链路段 | 源 IP | 目的 IP | 源 MAC | 目的 MAC |
|---|---|---|---|---|
| A → R2（经 S2） | 222.118.44.2 | 154.121.30.2 | 2A-2A-2A-2A-2A-2A | 1A-1A-1A-1A-1A-1A |
| R2 → R4（经 S1） | 222.118.44.2 | 154.121.30.2 | 4C-4C-4C-4C-4C-4C | 1C-1C-1C-1C-1C-1C |
| R4 → G（经 S4） | 222.118.44.2 | 154.121.30.2 | 1B-1B-1B-1B-1B-1B | 2B-2B-2B-2B-2B-2B |

IP 列三段全同；MAC 列逢 R2、R4 各换一对，R2 的 F 侧出接口（4C…）与 R4 的 F 侧入接口（1C…）在同一段 S1 上——同段两端接口的 MAC 字母位相同（都是 C 网段的 4C/1C）。A 判定异网（目的 & /20 掩码 ≠ 本机网络地址 222.118.32.0）→ 先 ARP 网关 1A-…；S2、S4 转发行四个字段全"不变"，只做自学习。

### ③ 自编综合拓扑题（串联 02/03/06/08/11/12 篇）

**题**（用总题图）：主机 N（122.98.44.4，MAC 4D-…-4D，子网 F /24）开机后访问内网 Web 服务器 DS-1（204.119.32.2:80，经防火墙后的 1G-…-1G 链路接入 R1）。问：
1. N 开机后如何自动获得网络配置？DHCP 服务器 DS-3 与 N 同网段，交互有何特点？若是跨网段获取靠什么？
2. N 输入域名 www.ex.com，第一次 DNS 查询的大致流程？（DNS 服务器 = DS-4，122.98.44.3）
3. N 发出的 TCP SYN 报文：源/目的 IP、源/目的端口分别是什么？
4. N 发出的第一个以太网帧：目的 MAC 是谁？写出具体值并说明理由。
5. R1 转发时改写什么？本路径存在 NAT 吗？图中哪个子网出网才需要 NAT？

**答**：
1. **DHCP**（DS-3 即服务器，与 N 同在子网 F）：DISCOVER（源 0.0.0.0，目的 255.255.255.255）广播 → OFFER（yiaddr=候选地址）→ REQUEST（源仍 0.0.0.0，yiaddr 回填 OFFER 给的候选地址，02 篇口径）→ ACK，取回 IP 122.98.44.4/掩码/网关（R1 的 122.98.44.1）/DS-4 的 DNS 地址；同网段**不需要中继代理**——变体：若 DHCP 服务器在别的网段，靠**中继代理**（通常在路由器）收到广播后单播转发，服务器按 giaddr 判断客户端网段（02 篇）。
2. N 查本机 hosts/缓存 → 未命中则问**本地域名服务器 DS-4**（递归，同网段直接交付）；DS-4 未命中则依次向根/顶级/权限服务器（迭代），最终把 IP 回给 N（02 篇）。
3. 源 IP=122.98.44.4、目的 IP=204.119.32.2；源端口=**短暂端口**（如 51234）、目的端口=**80**（03/06 篇）。
4. 目的 MAC=**1D-1D-1D-1D-1D-1D**（R1 面向子网 F 的接口）。N 判定异网（204.119.32.2 与 122.98.44.4 不同网）→ 间接交付，先交网关；对 122.98.44.1 做 ARP 得其 MAC；MAC 不出本网段（12 篇）。
5. R1 重写二层帧头（源 MAC=出接口、目的 MAC=防火墙 1G-…-1G）、TTL−1、重算 IP 首部校验和；**本路径无 NAT**——源/目的都是公网地址，纯路由转发 IP 头不变。图中只有**子网 B（172.18.32.0/26，私有地址）** 内的主机 D、E 出网访问公网时才需要 NAT（11 篇私有地址）；防火墙在此起边界过滤作用，不改变"IP 端到端不变"的规律。

### ④ 冲突域/广播域数数题

**步骤**：集线器不隔任何域（连一片算一个冲突域）；交换机每端口一个冲突域；路由器每接口一个广播域。
**自编例题**（用总题图）：子网 B 片段——D、E 接集线器 H1，H1 接交换机 S3，S3 另两端口接主机 F 与路由器 R3：
- 冲突域：D、E、H1、S3 下行口算 **1 个**（Hub 不隔离）；F 算 1 个；R3 侧算 1 个 → 共 **3 个**
- 广播域：片内没有路由器 → **1 个**（R3 另一侧才是新广播域）

变体：同一图里把 S3 换成 Hub，则 D、E、F、R3 全挤在 1 个冲突域里；把 R3 换成交换机，则广播域不变但少隔出一个冲突域——设备层次一变，域的数目立刻变。

## 6. 本节易错点

常见坑：
- "经过交换机 TTL 减 1"：错，交换机二层透明转发，**只有路由器才 TTL−1、重写帧头**
- "目的 MAC 填目的主机的 MAC"：跨网段时错——填**下一跳（网关）**的 MAC；只有同网直连才填目的主机
- "ARP 请求能穿过路由器"：错，广播帧出不了路由器，跨网段解析的是网关
- "交换机隔离广播域"：错，交换机只隔冲突域；隔离广播域靠路由器（或 VLAN）
- "源 IP 途中会被改写"：NAT 场景**会**（源私有地址换公网地址）；纯 IPv4 路由转发**不会**。题干标注 NAT 时 IP 列就不能写"全程不变"
- 填表时把"路由器入接口/出接口 MAC"写混：每段链路一对 MAC，入段填入口、出段填出口
- 冲突域数数把"交换机整体"算一个：错，按**端口**数
- 综合题跳步：先判同/异网再谈 ARP，先判 MTU 再谈分片，顺序错则后面全错
