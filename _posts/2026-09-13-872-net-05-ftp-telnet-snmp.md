## 2. 知识框架

```
FTP（文件传输协议）—— 控制连接 TCP 21 + 数据连接 TCP 20（主动）/随机（被动）
  └─ 特点：带外控制（out-of-band control），控制与数据分离

TELNET（远程登录）—— TCP 23，NVT（网络虚拟终端）格式
  └─ 已被 SSH 取代（SSH 加密，TELNET 明文）

SNMP（简单网络管理协议）—— UDP 161（代理）、UDP 162（Trap）
  └─ 管理站 + 代理 + MIB（管理信息库）
  └─ 操作：Get/GetNext/Set/Trap
```

- 三个协议都是"传统互联网协议"，FTP 和 TELNET 属于早期应用，SNMP 是网络运维核心
- FTP 的"带外控制"是考试重点：控制命令走 21 端口，数据走 20 端口，两者分离

## 3. 简答与名词解释

### 必背

- **FTP（文件传输协议）**：FTP 是用于在网络上进行文件传输的应用层协议，采用客户-服务器模式。FTP 使用两个 TCP 连接：控制连接（端口 21）用于传输命令和响应，数据连接（端口 20 或随机端口）用于传输文件内容。这种控制与数据分离的方式称为**带外控制**。
- **TELNET（远程登录协议）**：TELNET 是用于远程登录的应用层协议，TCP 端口 23。TELNET 定义了 NVT（网络虚拟终端）格式，使不同终端系统可以互操作。TELNET 明文传输，已被 SSH（加密远程登录）取代。
- **SNMP（简单网络管理协议）**：SNMP 是用于网络管理的应用层协议，采用管理站-代理模型。管理站向代理发送请求（Get/GetNext/Set），代理返回响应或主动发送 Trap 报警。SNMP 使用 UDP，代理监听端口 161，管理站监听端口 162（接收 Trap）。
- **MIB（管理信息库）**：MIB 是 SNMP 管理对象的集合，以树状结构组织，每个对象有唯一 OID（对象标识符）。管理站通过读取/设置 MIB 对象来监控和控制网络设备。

### 辨析

- **FTP 控制连接 vs 数据连接**：控制连接在整个会话期间保持打开，传输命令（USER/PASS/LIST/RETR/STOR）；数据连接在每次传输文件时建立，传输完毕后关闭。主动模式下服务器主动连接客户端的数据端口（20→客户端随机端口），被动模式下服务器打开随机端口等待客户端连接。
- **TELNET vs SSH**：TELNET 明文传输，SSH 加密；TELNET 端口 23，SSH 端口 22；TELNET 已淘汰，SSH 是现代远程登录标准。
- **SNMP v1/v2c/v3**：v1 最简单，明文团体名（community）；v2c 增强了性能但仍明文；v3 增加了认证和加密，安全性最高。考试通常只考 v1/v2c 的基本概念。

### 了解

- FTP 命令：USER（用户名）、PASS（密码）、LIST（列出目录）、RETR（下载）、STOR（上传）、QUIT（退出）
- FTP 响应码：2xx 成功、3xx 需要进一步信息、4xx 临时错误、5xx 永久错误
- SNMP Trap：代理主动向管理站发送报警消息（如接口 down、设备重启），无需管理站轮询

## 4. 易混对比表

| 协议 | 端口 | 传输层 | 控制方式 | 应用场景 |
|---|---|---|---|---|
| FTP | 21（控制）+ 20（数据） | TCP | 带外控制（控制与数据分离） | 文件传输 |
| TELNET | 23 | TCP | 带内控制（命令与数据混合） | 远程登录（已淘汰） |
| SSH | 22 | TCP | 加密传输 | 远程登录（现代标准） |
| SNMP | 161（代理）/162（Trap） | UDP | 请求-响应 + Trap | 网络管理 |

| SNMP 操作 | 方向 | 作用 |
|---|---|---|
| Get | 管理站→代理 | 读取 MIB 对象值 |
| GetNext | 管理站→代理 | 读取下一个 MIB 对象（遍历表） |
| Set | 管理站→代理 | 设置 MIB 对象值 |
| Trap | 代理→管理站 | 主动报警（无需轮询） |

## 5. 计算与方法

本节无复杂计算，重点是概念辨析和端口记忆。

### FTP 主动模式 vs 被动模式

**主动模式（PORT）**：
1. 客户端打开随机端口 N（>1024）连接服务器 21（控制连接）
2. 客户端发送 PORT 命令告知自己的数据端口 N+1
3. 服务器主动连接客户端端口 N+1（源端口 20）
4. 数据传输完毕后关闭数据连接

**被动模式（PASV）**：
1. 客户端连接服务器 21（控制连接）
2. 客户端发送 PASV 命令
3. 服务器返回自己的数据端口 P（随机端口）
4. 客户端主动连接服务器端口 P
5. 数据传输完毕后关闭数据连接

**区别**：主动模式下服务器主动连接客户端（可能被防火墙拦截），被动模式下客户端主动连接服务器（更易穿越防火墙）。

### SNMP 管理模型

```
管理站（Manager）                代理（Agent）
     |                              |
     |--- Get/GetNext/Set --------->| 读取/设置 MIB
     |<--- Response ----------------|
     |<--- Trap --------------------| 主动报警
```

- 管理站：网络管理中心的软件，轮询代理、接收 Trap
- 代理：被管设备上的 SNMP 进程，响应请求、发送 Trap
- MIB：代理上的管理对象库，按 OID 组织

## 6. 本节错题与易错点

- [ ] 待填：今日王道选择错因

常见坑：
- "FTP 数据连接用端口 21"：错，21 是控制连接，数据连接用 20（主动）或随机端口（被动）
- "SNMP 用 TCP"：错，SNMP 用 UDP（简单高效，适合网络管理）
- "TELNET 和 SSH 都是明文"：错，SSH 加密
- "SNMP Trap 是管理站发给代理"：错，Trap 是代理主动发给管理站
- "FTP 控制连接传输文件"：错，控制连接只传命令，文件走数据连接
