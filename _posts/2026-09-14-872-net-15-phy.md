## 2. 物理层的骨架

```
物理层任务：把比特流搬到传输媒体上，在一条物理信道内透明传比特
  ├─ 通信基础
  │    信号：模拟/数字；码元（固定时长的信号波形，携带 log₂V bit）
  │    通道方向：单工（广播）/ 半双工（对讲机）/ 全双工（电话、以太网全双工）
  │    传输方式：基带直送 / 带通调制；并行（短距）/ 串行（链路）；同步 / 异步
  ├─ 编码与调制（目的：让接收方能同步、能还原）
  │    归零/不归零 → 曼彻斯特（中间跳变=时钟+数据）→ 差分曼彻斯特（边界跳变只作同步）
  │    调制：ASK/FSK/PSK → QAM（幅相联合，码元种类数 M）
  ├─ 信道极限容量（两定理定上限）
  │    无噪声 → 奈奎斯特：低通 2W log₂V、带通 W log₂V
  │    有噪声 → 香农：W log₂(1+S/N)
  ├─ 复用（一条链路多路信号）
  │    FDM 分频 / TDM 分时隙 / WDM 分光波长 / CDM 分码；STDM 按需动态分配时隙
  ├─ 交换方式（把多段链路拼成端到端通路）
  │    电路交换（含 FDM/TDM 划分）｜报文交换｜分组交换
  └─ 设备：中继器（再生信号、延长网段）、集线器（多口中继、共享带宽、一个冲突域）
```

## 3. 要背的定义与辨析

### 必背（定义直接考）

- **奈奎斯特定理**：无噪声理想**低通**信道中，极限数据率 = **2W log₂ V**（b/s），W 为带宽（Hz），V 为码元离散电平（或码元种类）数，码元速率上限为 2W 波特；理想**带通**信道系数改为 W，即 R = **W log₂ V**。要提速率只能加大 V，但 V 越大码元间差异越小，抗噪声能力越差，所以真正的上限由香农定理给出。
- **香农定理**：有噪声信道极限数据率 = **W log₂(1+S/N)**（b/s），S/N 为信噪比；题目给分贝先换算：(S/N)dB = 10 lg(S/N) → S/N = 10^(dB/10)（30 dB = 1000 倍、3 dB ≈ 2 倍）。信道实际可达速率取奈氏与香农结果的较小值。
- **曼彻斯特编码**：每个码元**中间必有一次跳变**，该跳变既作时钟同步又承载数据。谢希仁教材口径：位周期中心"向上跳变（低→高）=0、向下跳变（高→低）=1"（注意：Thomas/Tanenbaum 体系定义相反，考题若先给定义则按题面判读，判读前先确认口径）。优点：自同步、无直流分量；每个比特含两个半位码元，信号变化率/带宽约为 NRZ 的两倍，编码效率 50%（10 Mb/s 以太网需 20 MBd 波特率）。以太网用它，是因为接收端能从波形本身恢复时钟，不依赖额外时钟线。
- **差分曼彻斯特编码**：每个码元中间必跳变只作同步，数据看码元开始边界，有跳变=0、无跳变=1。设计目的：接收端只需比较相邻码元边界是否跳变，不依赖绝对电平，即使传输中两线极性接反也能正确解码，抗极性反转、抗时钟偏移。
- **统计时分复用（STDM）**：时隙不固定分配给用户，而是**按需动态分配**，有数据才占用时隙，并携带用户地址标识。相比传统 TDM（每用户固定时隙，空闲时信道白白空转），STDM 提高线路利用率。代价：时隙不固定，每个分组必须带地址信息，且同一用户突发峰值可能超过其平均份额。
- **传统 TDM 的峰值拥塞**：n 路用户复用一条 W 波特链路，每路分得 W/n。即使所有用户平均速率之和 ≤ W，某用户瞬时峰值超过 W/n 时，其固定时隙装不下该速率的数据，依然会丢包/拥塞。TDM 静态分配无法应对突发流量，这正是 STDM 存在的理由。
- **电路交换**：通信前建立一条专用物理通路（可经 FDM/TDM 划分信道），**独占资源直至释放**。三阶段：建立 → 通话（数据直达，不再存储转发）→ 释放。特点：时延小、有序到达，但线路利用率低、无法应对突发，适合实时性要求高、连续大批量的传输。
- **卫星通信**：利用通信卫星作空中微波中继，地面站—卫星—地面站一跳直达，途中没有任何存储转发结点。特点：①覆盖范围广（海洋、山区、荒漠、灾区都能通），不受地面地形与基站限制；②频谱资源多、可用带宽大；③**传播距离极远导致传播时延很大**，地球同步轨道（GEO）卫星距地面约 3.6 万 km，光速传播单向约 240 ms（题目常取 250 ms），往返 RTT 约 500 ms。
- **卫星链路减少的是"存储转发时延"，不是传播时延**：卫星链路省掉了中间路由器的存储转发，所以排队时延与处理时延大幅减少甚至归零（一段直达、无路由器排队）；但**传播时延反而急剧增大**（比地面链路多几百毫秒）。这是"卫星通信减少了端到端哪类时延"的唯一正确答法，答"减少传播时延"是方向性错误。
- **时延四段的取舍**：排队时延（最不确定）、处理时延（最小）、传播时延（距离决定）、传输时延（速率决定）。地面长链路的问题是中间结点多，存储转发累计的排队+处理时延大；卫星链路的问题是跳数少但距离远，排队+处理为零、传播时延极大。两者是此消彼长的关系。

### 辨析（选择题考对比）

- **单工 vs 半双工 vs 全双工**：单工只能单向（广播、遥控）；半双工双向但分时交替（对讲机）；全双工可同时双向（电话、全双工以太网）。**判断步骤**：看"能否同时双向"——广播/遥控=单工，对讲机=半双工，电话/全双工以太网=全双工。全双工需要两条独立信道或频分/时分隔离，**以太网全双工不再需要 CSMA/CD**（联动 14 篇）；半双工才存在争用期计算，综合题把争用期算在物理层相关计算里，别只盯着链路层。
- **波特 vs 比特**：波特是码元/秒（信号变化次数），比特/秒 = 波特 × log₂V。"速率翻倍"题先分清说的是码元速率还是信息速率；QAM-16 每码元携带 log₂16=4 bit。
- **FDM vs TDM**：FDM 所有用户同时占用不同频段（需**保护频带**防串扰，浪费带宽）；TDM 所有用户轮流占用全部频带（需同步、时隙定长）。WDM 是光纤上的 FDM；CDM 用正交码区分。五类复用的对照见下文《信道复用》表。
- **STDM vs TDM**：逐行对比见下文《信道复用》表，辨析核心是"为什么 STDM 省带宽"——固定时隙空转浪费 vs 按需分配但每个分组必须带地址。
- **电路交换 vs 报文交换 vs 分组交换**：电路交换先建专用通路（时延小、独占、适合实时大批量）；报文交换整份存储转发（无建连，但报文大、占中间节点缓存久）；分组交换切分组流水转发（链路利用率最高、适合突发）。三者比较是选择高频点，**定性对比在 01 篇 §5，本节只算端到端时延账，计算见 §5④**。
- **卫星通信 vs 地面蜂窝（4G/5G）**：卫星靠空中中继不依赖地面基站，理论上覆盖全球、含海洋与灾区，终端密度低也能服务，适合宽带接入与应急通信；地面蜂窝靠密集基站，覆盖跟着基站走，人口密集区速率与容量远高于卫星。卫星的短板是传播时延大（交互类业务体验差、终端成本与功耗高、单星覆盖容量有限）；地面蜂窝的短板是依赖基础设施、盲区与灾害易中断。综合类简答题按"**广覆盖/不依赖地面设施/应急** vs **低时延/高容量/基站密集**"两侧对写即可。

### 通信基础：码元、传输方式与信道分类

- **码元**：固定时长的一个信号波形（离散信号单元）。码元可取 V 种电平/状态时，每个码元携带 log₂V bit；码元速率单位为波特（Baud），数据率 = 波特率 × log₂V。
- **基带传输 vs 带通（频带）传输**：基带传输把数字信号不搬频直接送上信道（以太网、曼彻斯特编码，标准名里的 `Base` 即基带）；带通传输先用载波把信号调制到合适频段再传（电话线上传数据、无线链路）。
- **并行传输 vs 串行传输**：并行一次发多位（短距离，如计算机内部总线）；串行逐位发送（长距离，网络链路几乎全是串行）。
- **同步传输 vs 异步传输**：同步传输靠统一时钟、以数据块（帧）为单位连续发送，效率高；异步传输每个字符加起始位/终止位，收发双方各用各的时钟，实现简单但开销大。曼彻斯特编码的自同步能力正是为了省掉单独时钟线。

### 编码与调制（波形判读见 §4.2）

- **数字数据 → 数字信号（编码）**：NRZ / RZ / 曼彻斯特 / 差分曼彻斯特，判读规则、效率与波形图见 §4。
- **数字数据 → 模拟信号（调制）**：ASK 幅移（抗噪最差）、FSK 频移（易实现、低速）、PSK 相移（抗噪较好）；QAM 幅相联合，星座点数 = 码元种类数 M，每码元 log₂M bit（如 QAM-16 = 4 bit/码元）。计算套路见 §5①②。

### 信道复用：FDM / TDM / STDM / WDM / CDM

| 复用方式 | 靠什么区分各路 | 关键词 |
|---|---|---|
| **FDM 频分** | 不同频段，各路同时传 | 保护频带防串扰；模拟主干 |
| **TDM 时分** | 固定时隙轮流传，时隙即身份 | 需同步、不带地址、怕突发 |
| **STDM 统计时分** | 按需动态分配时隙 | **必须带地址**、抗突发、利用率高 |
| **WDM 波分** | 不同光波长 | 本质是光纤上的 FDM |
| **CDM 码分** | 正交码片（码型） | 各路同频同时，靠码型分离（了解） |

**STDM vs TDM 逐行对比**（辨析核心："为什么 STDM 省带宽"）：

| 对比项 | TDM（同步时分） | STDM（统计时分） |
|---|---|---|
| 时隙分配 | 固定预分配 | 按需动态 |
| 空闲时隙 | 空转浪费 | 让给其他用户 |
| 是否带地址 | 不需要（时隙即身份） | **必须带地址** |
| 应对突发 | 差（峰值超份额即丢包） | 较好（动态借时隙） |
| 线路利用率 | 低 | 高 |

## 4. 对比与速查

### 4.1 四种编码对照

四种编码的判读规则、设计目的与效率：

| 编码 | 判读规则 | 设计目的 | 效率 |
|---|---|---|---|
| 曼彻斯特 | 中间跳变=数据+时钟 | 自同步、消直流 | 50% |
| 差分曼彻斯特 | 中间跳变只同步；边界有跳=0 无跳=1 | 抗极性接反、抗时钟漂移 | 50% |
| 不归零制（NRZ） | 正电平=1，负电平=0（无同步机制） | 简单、带宽最省 | 100%（但难同步） |
| 归零制（RZ） | 正脉冲=1，负脉冲=0；每位中间回到零 | 提供同步参考 | 50%（每比特 2 码元，带宽约为 NRZ 两倍） |

### 4.2 波形判读：不归零 / 归零 / 曼彻斯特 / 差分曼彻斯特

![图 2-2 数字信号常用编码方法：不归零、归零、曼彻斯特、差分曼彻斯特](/assets/img/csreview/wulicengbianma.png)

*图 2-2　数字信号常用的编码方法（复习用示意图）*

- **不归零制（NRZ）**：正电平代表 1，负电平代表 0；没有位内跳变，接收端不能从波形本身提取时钟，**没有自同步能力**。
- **归零制（RZ）**：正脉冲代表 1，负脉冲代表 0；每位中间回到零，提供同步参考，但占用带宽更大。
- **曼彻斯特编码**：位周期中心**向上跳变代表 0，向下跳变代表 1**（本笔记按谢希仁口径；也可反过来定义，考题若先给定义按题面判读）。每位中间必跳变，**跳变既作时钟又承载数据**，因此具有自同步能力；信号频率/带宽约为 NRZ 的两倍。
- **差分曼彻斯特编码**：每位中心**始终有跳变**，但只作同步；数据看**位开始边界**——有跳变代表 0，无跳变代表 1。优点是抗极性反转、抗时钟漂移。

> 判读口诀：**曼彻斯特看中间（上 0 下 1，中间跳变既同步又载数据），差分看边界（有 0 无 1，中间跳变只同步）**。用图上比特串 `1 0 0 0 1 0 0 1 1 1` 自测：先按曼彻斯特看每位中心跳变方向，再按差分曼彻斯特看每位起始边界有无跳变。

### 4.3 物理层设备与卫星通信速查

物理层设备的层次与局限：

| 设备 | 层次 | 做什么 | 局限 |
|---|---|---|---|
| 中继器 | 物理层 | 再生放大信号，延长网段 | 不识别帧，两端同协议同速率 |
| 集线器 | 物理层 | 多口中继：比特广播式转发 | 共享带宽、一个冲突域、半双工 |

卫星通信与地面蜂窝的逐维对照：

| 对比项 | 地面蜂窝（4G/5G） | 卫星通信 |
|---|---|---|
| 中继与时延 | 基站多跳存储转发，排队/处理时延不确定 | 空中一跳直达，基本无排队与处理时延 |
| 传播时延 | 小（亚毫秒） | **极大**（GEO 单向约 240 ms、RTT 约 500 ms） |
| 覆盖 | 跟基站走，有盲区 | 全球覆盖，含海洋/山区/灾区 |
| 容量与短板 | 密集区容量大、可网状扩容；依赖地面设施、灾害易断 | 频谱宽但单星容量有限；终端贵且耗电、交互体验差 |

> 记法：两定理"**无噪奈氏找 V，有噪香农找 S/N，最后取小（低通 2W、带通 W）**"；差分曼彻斯特"**边界定 01，中间只对表**"；TDM 坑"**平均不超不等于不拥塞，峰值超份额照样丢**"；卫星坑"**省的是排队处理，涨的是传播时延**"。

## 5. 五类计算套路

### ① 两定理选择与计算（本章压轴）

**触发条件**：给带宽/电平数/信噪比，求极限速率或反解参数。

**步骤**：

1. 题干无噪声 → 奈氏：R = 2W log₂V（理想**低通**；理想**带通**系数为 W，即 R = W log₂V）；问"最多几电平"则反解 V = 2^(R/2W)
2. 题干有噪声/给 dB → 先换算 S/N = 10^(dB/10)，再香农：R = W log₂(1+S/N)
3. 两条件都给 → 各算一个取 min（谁是瓶颈谁说了算，不能预设）
4. QAM 计算套路：奈氏定波特率上限 → 每码元 log₂M bit → 相乘得比特率

**自编例题**：带宽 4 kHz，QAM-16 调制，无噪声（低通）：

码元速率上限 = 2×4000 = 8000 波特；每码元 log₂16 = 4 bit；速率 = 8000×4 = **32 kb/s**。

**自编例题 2**：带宽 3 kHz，信噪比 30 dB：

S/N = 10^(30/10) = 1000；香农速率 = 3000×log₂1001 ≈ 3000×9.97 ≈ **29.9 kb/s**。

若题目同时给 16 电平，奈氏要再算一道：2×3000×log₂16 = 6000×4 = **24 kb/s**；取 min(24, 29.9) = **24 kb/s**——这题反而是奈氏卡脖子。可见 min 规则不能预设谁是瓶颈，必须两个都算。

### ② 波特率与编码效率换算

**步骤**：

- **多电平调制**：比特率 = 波特率 × log₂V（V 为码元电平数，QAM-16 即每码元 4 bit）；
- **曼彻斯特系（曼彻斯特/差分曼彻斯特）**：每个比特被切成两个半位码元、每码元只携带 1/2 bit，因此**波特率 = 2×比特率**，编码效率 50%。这与多电平"用 log₂V 提速率"是两个独立机制，别混。

**自编例题**：10 Mb/s 曼彻斯特编码以太网，每码元携带 1/2 bit，码元速率 = 10 Mb/s ÷ 0.5 = **20 M 波特（MBd）**，所需带宽约为 NRZ 的两倍（NRZ 同速率只需 10 MBd）。

### ③ STDM/TDM 利用率分析

**触发条件**：n 路用户、每路速率/峰值给定，问复用方案是否丢包或需要多大链路。

**步骤**：

1. TDM：每路份额 = 链路/n；任一用户峰值 > 份额则该路丢包（即使总平均 ≤ 链路）
2. STDM：时隙动态给，平均带宽够用即可；但所有用户同时满发时仍可能拥塞，需要缓存
3. 算"等效用户数"：STDM 链路可承载用户数 ≈ 链路速率/每路平均速率（超额订阅）

**自编例题**：链路 10 Mb/s，10 路用户平均 1 Mb/s、峰值 3 Mb/s。TDM 每路 1 Mb/s：峰值 3 超份额 → **丢包**；STDM：平均占用合计 10 Mb/s 恰满载，同时突发仍需缓存，说明 TDM 的固定分配扛不住突发。

### ④ 三种交换方式总时延计算

**口径**：三种交换方式的定性优劣（独占通路 / 存储转发 / 统计复用）在 01 篇 §5 已对比，本节只算端到端时延账。

**触发条件**：报文 x bit 分成 p 个分组，每段链路速率 R，端到端共 k 段链路（即 k−1 个中间结点），比较三种交换的总时延。

**步骤**（先钉死口径：k = 链路段数，存储转发都按"每段链路"算）：

1. 电路交换：建立时间 t₀ + x/R + 传播（数据直达、不存储转发；t₀ 是否含释放按题面）
2. 报文交换：整份报文在每个结点全收全转，每段链路都发一遍 x：k × (x/R) + 传播
3. 分组交换：每分组发送时延 = (x/p)/R，流水线并行 → **(k + p − 1) × 每分组时延** + 传播。为什么是 k+p−1：第 1 个分组要逐段走满 k 段，花 k×每分组时延；它进入流水后，每隔一个"每分组时延"就有一个分组到达终点，后面 p−1 个分组只需再多等 (p−1)×每分组时延，两段相加即 (k+p−1)×每分组时延
4. **首部陷阱**：若每分组另加 h bit 首部，每段链路实传的是 (x/p + h)，全网还多发 p×h 的总首部，严格算把 (x/p)/R 换成 (x/p + h)/R
5. 结论：**分组 < 报文**（流水并行）；报文很短时电路交换（忽略 t₀）最快，报文大且突发时分组优

**自编例题**：x = 10⁷ bit，R = 10 Mb/s（x/R = 1 s = 1000 ms），k = 5，p = 1000（不计首部）：

- 分组：每分组 10⁴ bit → 1 ms；总时延 ≈ (5 + 1000 − 1) × 1 ms = **1004 ms**
- 报文：5 × 1000 ms = 5000 ms，分组流水并行的优势一目了然
- 电路：t₀ + 1000 ms；若 t₀ = 1 s 则共 2000 ms，反比分组慢（谁快取决于 t₀ 与报长）

### ⑤ 卫星链路的时延、窗口与序号位数计算

**触发条件**：给卫星链路速率、单向传播时延、帧长（或窗口大小），问利用率、至少多大发送窗口、帧序号至少几比特。

> **口径提醒**：本篇问的"窗口要多大"是**窗口下限 = 速率 × RTT**，属工程口径；教材的时延带宽积 = 带宽 × 单向传播时延，是它的一半。判别表见 01 篇 §3.5.1。**考题若问"时延带宽积"，用单向传播时延，别把 RTT 套进去。**

**步骤**：

1. 单向传播时延 t_p（GEO 约 240 ms，题目一般直接给 250 ms）→ RTT = 2×t_p（忽略确认帧发送时延与处理时延；含确认帧 T_A 的完整式见 01 篇 §3.7）
2. 单帧发送时延 T_D = 帧长 / 速率
3. 停等协议利用率 U = T_D / (T_D + RTT)。RTT 远大于 T_D 时 U 趋近 0，这就是卫星链路必须开大窗口、不能用停等的原因
4. 要 U ≥ 目标值 u（如 80%）：**W ≥ ⌈u·(T_D + RTT)/T_D⌉ = ⌈u·(1 + RTT/T_D)⌉**；只有问"**灌满管道**（U=100%）"时才用 W ≥ ⌈(T_D + RTT)/T_D⌉ = 1 + ⌈RTT/T_D⌉
5. 再用序号空间卡一道：GBN 需 2ⁿ ≥ W + 1、SR 需 2ⁿ ≥ 2W（14 篇 §5⑥）

**自编例题**：卫星链路 128 kb/s，单向传播时延 250 ms，帧长 1000 B，不计确认帧开销。

T_D = 8000 bit / 128×10³ = 62.5 ms；RTT = 2×250 = 500 ms。

- 停等：U = 62.5 / (62.5 + 500) ≈ **11%**，远达不到 80%
- 要 U ≥ 80%：W ≥ ⌈0.8 × (62.5 + 500)/62.5⌉ = ⌈0.8 × 9⌉ = ⌈7.2⌉ = **8 帧**
- GBN 下需 2ⁿ ≥ 8 + 1 = 9：2³=8 < 9、2⁴=16 ≥ 9 → 帧序号至少 4 比特

**自检**：答案代回去 U = W·T_D / (T_D + RTT)：W=8 时 8×62.5/562.5 ≈ **89%** ≥ 80% ✓；W=7 时 7×62.5/562.5 ≈ 78%，差一点；W=9 时 100%，那是"灌满管道"口径，不是 80% 门槛。

## 6. 最容易写错的十三处

- 有噪声题用奈氏、无噪声题用香农：公式张冠李戴，先判"有无噪声"再动笔；奈氏还要看低通（2W）还是带通（W），系数差一倍
- 忘把 dB 换算成倍数：30 dB=1000 倍、3 dB≈2 倍，直接把 30 当 S/N 代入必错
- 两条件都给时只用一个公式：正确做法是各算取 min，且不能预设谁是瓶颈（见 §5① 例题 2：香农 29.9 却被奈氏 24 卡住）
- 差分曼彻斯特把"中间跳变"当数据：中间只同步，数据看边界有无跳变（有跳=0、无跳=1）
- "STDM 不需要地址信息"：反了，时隙不固定则**必须带地址**；TDM 才靠时隙位置识别用户
- "总平均速率不超链路带宽就不丢包"：TDM 下错，**峰值超份额照样丢**，这是复用一节的经典设错点
- "集线器能隔离冲突域"：错，Hub 全端口一个冲突域；隔离冲突域是交换机（14 篇）
- 波特率直接当比特率：多电平调制差一个 log₂V（QAM-16 是 4 bit/码元不是 16）；曼彻斯特恰好反过来——每码元只带 1/2 bit，**波特率是比特率的 2 倍**
- 全双工以太网还在算争用期：全双工无碰撞，CSMA/CD 不适用；半双工（Hub、对讲机模式）才有争用期
- **"卫星通信减少了传播时延"**：错，方向反了，卫星省掉的是中间路由器的存储转发（排队 + 处理）时延，传播时延反而大幅增加（GEO 往返约 500 ms）
- "卫星链路时延小所以适合实时交互"：错，卫星是典型大传播时延链路，交互类业务体验最差
- 卫星链路用停等协议也能跑满带宽：错，U = T_D/(T_D+RTT) 远小于 1，必须开 W ≥ 1+RTT/T_D 的大窗口才可能跑满
- 算窗口时把单向传播时延当 RTT：RTT = 2× 单向传播时延（确认帧还要飞回来）；问"目标利用率"用 u 乘管道容量，只有问"灌满"才取整到 1+RTT/T_D
