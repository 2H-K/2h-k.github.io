## 2. 知识框架

```
物理层任务：把比特流搬到传输媒体上——在一条物理信道内透明传比特
  ├─ 通信基础
  │    信号：模拟/数字；码元（固定时长的信号波形，携带 log₂V bit）
  │    通道方向：单工（广播）/ 半双工（对讲机）/ 全双工（电话、以太网全双工）
  ├─ 编码与调制（目的：让接收方能同步、能还原）
  │    归零/不归零 → 曼彻斯特（中间跳变=时钟+数据）→ 差分曼彻斯特（边界跳变只作同步）
  │    调制：ASK/FSK/PSK → QAM（幅相联合，码元种类数 M）
  ├─ 信道极限容量（两定理定上限）
  │    无噪声 → 奈奎斯特：2W log₂V
  │    有噪声 → 香农：W log₂(1+S/N)
  ├─ 复用（一条链路多路信号）
  │    静态：FDM / TDM / WDM / CDM；动态：STDM 按需分配时隙
  └─ 交换方式（把多段链路拼成端到端通路）
       电路交换（含 FDM/TDM 划分）｜报文交换｜分组交换
```

## 3. 简答与名词解释

### 必背

- **奈奎斯特定理**：**无噪声**理想低通信道中，极限数据率 = **2W log₂ V**（b/s），W 为带宽（Hz），V 为码元离散电平（或码元种类）数。它限制**码元速率 ≤ 2W 波特**；要提速率只能加大 V——但 V 越大码元间差异越小，抗噪声能力越差，所以真正的上限由香农定理给出。
- **香农定理**：**有噪声**信道极限数据率 = **W log₂(1+S/N)**（b/s），S/N 为信噪比；题目给分贝先换算：**(S/N)dB = 10 lg(S/N) → S/N = 10^(dB/10)**（30 dB = 1000 倍、3 dB ≈ 2 倍）。信道实际可达速率取奈氏与香农结果的**较小值**。
- **曼彻斯特编码**：每个码元**中间必有一次跳变**，该跳变**既作时钟同步又承载数据**（经典定义：前低后高=1，或反之，以教材为准）。优点：自同步、无直流分量；代价：**编码效率 50%**（10 Mb/s 以太网需 20 MBd 波特率）。
- **差分曼彻斯特编码**：每个码元**中间必跳变只作同步**；数据看**码元开始边界**——**有跳变=0、无跳变=1**。设计目的：接收端只需比较相邻码元边界是否跳变，**不依赖绝对电平**，即使传输中两线极性接反也能正确解码，抗极性反转、抗时钟偏移。
- **统计时分复用（STDM）**：时隙**不固定分配**给用户，而是**按需动态分配**——有数据才占用时隙，并携带用户地址标识。相比传统 TDM（每用户固定时隙，空闲时信道白白空转），STDM 提高线路利用率。代价：**时隙不固定 → 每个分组必须带地址信息**，且同一用户突发峰值可能超过其平均份额。
- **传统 TDM 的峰值拥塞**：n 路用户复用一条 W 波特链路，每路分得 W/n。即使**所有用户平均速率之和 ≤ W**，某用户**瞬时峰值超过 W/n** 时，其固定时隙装不下该速率的数据，依然会**丢包/拥塞**——TDM 静态分配无法应对突发流量，这正是 STDM 存在的理由。
- **电路交换**：通信前**建立一条专用物理通路**（可经 FDM/TDM 划分信道），**独占资源直至释放**。三阶段：建立 → 通话（数据直达，不再存储转发）→ 释放。特点：时延小、有序到达，但线路利用率低、无法应对突发，适合实时性要求高、连续大批量的传输。

### 辨析

- **单工 vs 半双工 vs 全双工**：单工只能单向（广播、遥控）；半双工双向但**分时交替**（对讲机）；全双工可同时双向（电话）。注意：全双工需要**两条独立信道或频分/时分隔离**，以太网全双工不再需要 CSMA/CD（联动 14 篇）。
- **波特 vs 比特**：波特是码元/秒（信号变化次数），比特/秒 = 波特 × log₂V。"速率翻倍"题先分清说的是码元速率还是信息速率；QAM-16 每码元携带 log₂16=4 bit。
- **调制方式**：ASK 幅移（抗噪最差）、FSK 频移（易实现、低速）、PSK 相移（抗噪较好）；QAM 幅相联合，码元种类数 = 星座点数，比特/码元 = log₂M。考计算：给波特率与 M 求比特率。
- **FDM vs TDM**：FDM **所有用户同时**占用不同频段（需**保护频带**防串扰，浪费带宽）；TDM 所有用户**轮流**占用全部频带（需同步、时隙定长）。WDM 是光纤上的 FDM；CDM 用正交码区分（考了解）。
- **STDM vs TDM 对比表**（辨析核心："为什么 STDM 省带宽"）：

| 对比项 | TDM（同步时分） | STDM（统计时分） |
|---|---|---|
| 时隙分配 | 固定预分配 | 按需动态 |
| 空闲时隙 | 空转浪费 | 让给其他用户 |
| 是否带地址 | 不需要（时隙即身份） | **必须带地址** |
| 应对突发 | 差（峰值超份额即丢包） | 较好（动态借时隙） |
| 线路利用率 | 低 | 高 |

- **电路交换 vs 报文交换 vs 分组交换**：电路交换先建专用通路（时延小、独占、适合实时大批量）；报文交换整份存储转发（无建连，但报文大、占中间节点缓存久）；分组交换切分组流水转发（链路利用率最高、适合突发）——三者比较是选择高频点，计算见 §5④。

## 4. 易混对比表

| 编码 | 判读规则 | 设计目的 | 效率 |
|---|---|---|---|
| 曼彻斯特 | 中间跳变=数据+时钟 | 自同步、消直流 | 50% |
| 差分曼彻斯特 | 中间跳变只同步；边界有跳=0 无跳=1 | 抗极性接反、抗时钟漂移 | 50% |
| NRZ | 高=1 低=0（无同步机制） | 简单、带宽最省 | 100%（但难同步） |

| 设备 | 层次 | 做什么 | 局限 |
|---|---|---|---|
| 中继器 | 物理层 | 再生放大信号，延长网段 | 不识别帧，两端同协议同速率 |
| 集线器 | 物理层 | 多口中继：比特广播式转发 | 共享带宽、一个冲突域、半双工 |

> 记法：两定理"**无噪奈氏找 V，有噪香农找 S/N，最后取小**"；差分曼彻斯特"**边界定 01，中间只对表**"；TDM 坑"**平均不超不等于不拥塞，峰值超份额照样丢**"。

## 5. 计算与方法

### ① 两定理选择与计算（本章压轴）

**触发条件**：给带宽/电平数/信噪比，求极限速率或反解参数。

**步骤**：
1. 题干**无噪声** → 奈氏：R = 2W log₂V；问"最多几电平"则反解 V = 2^(R/2W)
2. 题干**有噪声/给 dB** → 先换算 S/N = 10^(dB/10)，再香农：R = W log₂(1+S/N)
3. 两条件都给 → 各算一个取 **min**（谁是瓶颈谁说了算）
4. QAM 计算套路：奈氏定波特率上限 → 每码元 log₂M bit → 相乘得比特率

**自编例题**：带宽 4 kHz，QAM-16 调制，无噪声：
码元速率上限 = 2×4000 = 8000 波特；每码元 log₂16 = 4 bit；速率 = 8000×4 = **32 kb/s**。

**自编例题 2**：带宽 3 kHz，信噪比 30 dB：
S/N = 10^(30/10) = 1000；速率 = 3000×log₂1001 ≈ 3000×9.97 ≈ **29.9 kb/s**。
若同时给 16 电平，则受香农限制仍取 29.9（min 规则）。

### ② 波特率与编码效率换算

**步骤**：比特率 = 波特率 × log₂V；曼彻斯特系编码 V=2（每码元 1 bit）→ **波特率 = 2×比特率**。
**自编例题**：10 Mb/s 曼彻斯特编码以太网需要多少波特率与带宽？10×10⁶ b/s ÷ 1 bit/码元 = 10 Mbit/码元 → 波特率 20 MBd；带宽约为 NRZ 两倍。

### ③ STDM/TDM 利用率分析

**触发条件**：n 路用户、每路速率/峰值给定，问复用方案是否丢包或需要多大链路。

**步骤**：
1. TDM：每路份额 = 链路/n；**任一用户峰值 > 份额 → 该路丢包**（即使总平均 ≤ 链路）
2. STDM：时隙动态给，平均带宽够用即可；但**所有用户同时满发**时仍可能拥塞 → 需要缓存
3. 算"等效用户数"：STDM 链路可承载用户数 ≈ 链路速率/每路平均速率（超额订阅）

**自编例题**：链路 10 Mb/s，10 路用户平均 1 Mb/s、峰值 3 Mb/s。TDM 每 路 1 Mb/s：峰值 3 超份额 → **丢包**；STDM：平均占用合计 10 Mb/s 恰满载，同时突发仍需缓存——说明 TDM 的固定分配扛不住突发。

### ④ 三种交换方式比较

**触发条件**：报文 x bit 分成 p 个分组，链路速率 R、k 段链路，比较总时延。

**步骤**：
1. 电路交换：建立时间 t₀ + x/R + 传播时延（数据直达不存储转发）
2. 报文交换：每跳整份存转 → k 段：k×(x/R) + 传播
3. 分组交换（流水线）：(k+p−1)×(分组发送时延) + 传播（各段并行流水）
4. 结论：**分组 < 报文**（流水并行）；报文小时电路快、报文大且突发时分组优

### ⑤ 全双工/半双工场景判断

**步骤**：看"能否同时双向"→ 电话/全双工以太网=全双工；对讲机=半双工；广播=单工。
注意联动：全双工以太网（交换机+两对线）**无需 CSMA/CD**（14 篇）；半双工才存在争用期计算——综合题把争用期算在物理层相关计算里，别只盯着链路层。

## 6. 本节易错点

常见坑：
- 有噪声题用奈氏、无噪声题用香农：公式张冠李戴——**先判"有无噪声"再动笔**
- 忘把 dB 换算成倍数：30 dB=1000 倍、3 dB≈2 倍，直接把 30 当 S/N 代入必错
- 两条件都给时只用一个公式：正确做法是**各算取 min**
- 差分曼彻斯特把"中间跳变"当数据：中间只同步，**数据看边界有无跳变**（有跳=0、无跳=1）
- "STDM 不需要地址信息"：反了，时隙不固定 → **必须带地址**；TDM 才靠时隙位置识别用户
- "总平均速率不超链路带宽就不丢包"：TDM 下错——**峰值超份额照样丢**，这是复用一节的经典设错点
- "集线器能隔离冲突域"：错，Hub 全端口一个冲突域；隔离冲突域是交换机（14 篇）
- 波特率直接当比特率：差一个 log₂V；QAM-16 是 4 bit/码元不是 16
- 全双工以太网还在算争用期：全双工无碰撞，CSMA/CD 不适用
