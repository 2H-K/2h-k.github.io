## 2. 物理层的骨架

```
物理层任务：把比特流搬到传输媒体上，在一条物理信道内透明传比特
  ├─ 通信基础
  │    信号：模拟/数字；码元（固定时长的信号波形，携带 log₂V bit）
  │    通道方向：单工（广播）/ 半双工（对讲机）/ 全双工（电话、以太网全双工）
  │    传输方式：基带直送 / 带通调制；并行（短距）/ 串行（链路）；同步 / 异步
  ├─ 编码与调制（目的：让接收方能同步、能还原）
  │    归零/不归零 → 曼彻斯特（中间跳变=时钟+数据）→ 差分曼彻斯特（边界跳变只作同步）
  │    调制：ASK/FSK/PSK → QAM（幅相联合，码元种类数 M）
  ├─ 信道极限容量（两定理定上限）
  │    无噪声 → 奈奎斯特：低通 2W log₂V、带通 W log₂V
  │    有噪声 → 香农：W log₂(1+S/N)
  ├─ 复用（一条链路多路信号）
  │    FDM 分频 / TDM 分时隙 / WDM 分光波长 / CDM 分码；STDM 按需动态分配时隙
  └─ 设备：中继器（再生信号、延长网段）、集线器（多口中继、共享带宽、一个冲突域）
```

> 三种交换方式（电路/报文/分组）属于概述内容，统一在 [01 篇 §5.1](/posts/872-net-01-overview/) 讲，本篇不展开。

下面正文严格按这五支展开：§3 通信基础 → §4 极限容量 → §5 编码与调制 → §6 复用 → §7 设备；§8 是骨架外的综合应用专题（卫星链路）。

## 3. 通信基础：比特要怎样被搬上信道

物理层不关心帧、不关心路由，它只解决一件事：**把 0/1 比特变成信号波形，透明地送上传输媒体**。这一节先建立后面要用的全套语言：信号长什么样、一个波形能带几个比特、信道能不能同时双向、信号是直送还是搬频。

### 3.1 信道与信号

- **信道**：信息传输的媒介或路径，可以是物理的（电缆、光纤），也可以是无线的（电磁波）。
- **信号**：载有信息的物理现象（电信号、光信号、无线电波）。**模拟信号**取值连续，**数字信号**取值离散。计算机发出的是数字信号，物理层要做的就是把离散的比特表示成具体波形。

### 3.2 码元、波特与比特率

**码元**是固定时长的一个信号波形（离散信号单元）。一个码元可以只带 1 bit，也可以带多个比特——关键看它能取多少种状态：

- 码元可取 **V 种电平/状态**时，每个码元携带 **log₂V bit**。
- 直觉：把振幅分成 4 档（低/中/高/很高），一个码元振幅是哪一档就对应 00/01/10/11，于是一个码元携带 log₂4 = 2 bit。档数越多，单个码元带的比特越多。

两个速率单位由此而来：

- **波特率（Baud）**：每秒传输的码元数（信号变化次数）；
- **比特率（b/s）**：每秒传输的比特数，**比特率 = 波特率 × log₂V**。

> **注意**：波特率不能直接当比特率。QAM-16 有 16 种码元状态，每码元携带 log₂16 = **4 bit**，不是 16 bit。"速率翻倍"题先分清说的是码元速率还是信息速率。

### 3.3 通信方向：单工 / 半双工 / 全双工

| 方式 | 能否同时双向 | 例子 |
|---|---|---|
| **单工** | 只能单向 | 广播、遥控 |
| **半双工** | 双向但分时交替 | 对讲机 |
| **全双工** | 可同时双向 | 电话、全双工以太网 |

**判断步骤**：看"能否同时双向"——广播/遥控 = 单工，对讲机 = 半双工，电话/全双工以太网 = 全双工。全双工需要两条独立信道，或用频分/时分把两个方向隔离。

> **注意**：**以太网全双工不再需要 CSMA/CD**（没有碰撞可检测）；只有半双工模式（Hub、对讲机模式）才存在争用期计算。综合题把争用期算在物理层相关计算里，别只盯着链路层。

### 3.4 传输方式：基带/带通、并行/串行、同步/异步

- **基带传输 vs 带通（频带）传输**：基带传输把数字信号**不搬频直接送上信道**（以太网、曼彻斯特编码，标准名里的 `Base` 即基带）；带通传输先用**载波把信号调制到合适频段**再传（电话线上传数据、无线链路）。
- **并行传输 vs 串行传输**：并行一次发多位（短距离，如计算机内部总线）；串行逐位发送（长距离，网络链路几乎全是串行）。
- **同步传输 vs 异步传输**：同步传输靠统一时钟、以数据块（帧）为单位连续发送，效率高；异步传输每个字符加起始位/终止位，收发双方各用各的时钟，实现简单但开销大。**曼彻斯特编码的自同步能力正是为了省掉单独的时钟线**（见 §5.1）。

## 4. 信道能跑多快：奈奎斯特与香农

不管编码怎么设计，一条信道的速率都有上限，而且要分两种情况：**无噪声**的理想信道由奈奎斯特定理管，**有噪声**的真实信道由香农定理管。两个定理给出的上限取较小值，才是实际可达速率。

### 4.1 奈奎斯特：无噪声信道

**奈奎斯特定理**：无噪声理想**低通**信道中，极限数据率

$$R = 2W\log_2 V \quad (\text{b/s})$$

W 为带宽（Hz），V 为码元离散电平（码元种类）数，码元速率上限为 **2W 波特**。理想**带通**信道系数改为 W，即 **R = W log₂V**。

"2"从哪来：奈奎斯特采样/无码间串扰理论证明，带宽为 W 的理想低通信道，每秒最多传输 2W 个码元而不产生码间串扰。公式的本质就是"每秒码元数 × 每码元比特数"。

想提速率只能加大 V，但 **V 越大码元间差异越小，抗噪声能力越差**——所以无噪声算出来的上限在真实信道里守不住，真正的上限还要看香农定理。

### 4.2 香农：有噪声信道

**香农定理**：有噪声信道的极限数据率

$$R = W\log_2(1 + S/N) \quad (\text{b/s})$$

S/N 为信噪比（信号功率/噪声功率）。题目给分贝要先换算：

$$(S/N)_{\text{dB}} = 10\lg(S/N), \quad S/N = 10^{\text{dB}/10}$$

常用换算：**30 dB = 1000 倍、3 dB ≈ 2 倍**。

### 4.3 min 规则：两个上限取小

信道实际可达速率 = **min(奈氏结果, 香农结果)**。谁是瓶颈谁说了算，不能预设：

- 题目只给无噪声条件 → 只用奈氏；
- 只给噪声条件 → 只用香农；
- 两条件都给 → 各算一个取 min。

> **注意**：① 公式别张冠李戴——先判"有无噪声"再动笔，奈氏还要看低通（2W）还是带通（W），系数差一倍；② 别把 dB 直接当 S/N 代入，30 当 1000 才算对。

### 4.4 例题

**例题 1（QAM + 奈氏）**：带宽 4 kHz，QAM-16 调制，无噪声（低通）：

码元速率上限 = 2×4000 = 8000 波特；每码元 log₂16 = 4 bit；速率 = 8000×4 = **32 kb/s**。

**例题 2（两定理取 min）**：带宽 3 kHz，信噪比 30 dB，且为 16 电平：

- 香农：S/N = 10^(30/10) = 1000，R = 3000×log₂1001 ≈ 3000×9.97 ≈ **29.9 kb/s**；
- 奈氏：R = 2×3000×log₂16 = 6000×4 = **24 kb/s**；
- 取 min = **24 kb/s**——这题反而是奈氏卡脖子。可见 min 规则不能预设谁是瓶颈，必须两个都算。

## 5. 编码与调制：让接收方能同步、能还原

上一节回答了"最多能跑多快"，这一节回答"具体用什么波形表示比特"。分两类：**数字数据 → 数字信号叫编码**，**数字数据 → 模拟信号叫调制**。两者的共同目的都是让接收方**能同步、能还原**。

### 5.1 数字编码：NRZ / RZ / 曼彻斯特 / 差分曼彻斯特

**不归零制（NRZ）**：正电平代表 1，负电平代表 0，整个码元周期电平不变。没有位内跳变，接收端不能从波形本身提取时钟，**没有自同步能力**；优点是简单、带宽最省（效率 100%，但难同步）。

**归零制（RZ）**：正脉冲代表 1，负脉冲代表 0，**每位中间回到零电平**，提供同步参考；但每比特占两个码元，带宽约为 NRZ 两倍，效率 50%。

**曼彻斯特编码**：每个码元**中间必有一次跳变**，该跳变**既作时钟同步又承载数据**。谢希仁教材口径：位周期中心"**向上跳变（低→高）= 0、向下跳变（高→低）= 1**"。

- 优点：自同步（接收端能从波形本身恢复时钟，不依赖额外时钟线）、无直流分量；
- 代价：每个比特含两个半位码元，信号变化率/带宽约为 NRZ 的两倍，**编码效率 50%**。
- 以太网用它，正是看上自同步能力。

> **注意口径**：Thomas/Tanenbaum 体系对曼彻斯特的 0/1 定义相反。考题若先给定义则按题面判读，判读前先确认口径。

**差分曼彻斯特编码**：每个码元**中间必跳变，但只作同步**；数据看码元**开始边界**——**有跳变 = 0、无跳变 = 1**。

- 设计目的：接收端只需比较相邻码元边界是否跳变，不依赖绝对电平，即使传输中两线极性接反也能正确解码，**抗极性反转、抗时钟偏移**。
- 效率同样为 50%。

> **判读口诀**：**曼彻斯特看中间（上 0 下 1，中间跳变既同步又载数据），差分看边界（有 0 无 1，中间跳变只同步）**。用图上比特串 `1 0 0 0 1 0 0 1 1 1` 自测：先按曼彻斯特看每位中心跳变方向，再按差分曼彻斯特看每位起始边界有无跳变。

**四种编码对照**：

| 编码 | 判读规则 | 设计目的 | 效率 |
|---|---|---|---|
| 曼彻斯特 | 中间跳变 = 数据 + 时钟 | 自同步、消直流 | 50% |
| 差分曼彻斯特 | 中间跳变只同步；边界有跳 = 0 无跳 = 1 | 抗极性接反、抗时钟漂移 | 50% |
| 不归零制（NRZ） | 正电平 = 1，负电平 = 0（无同步机制） | 简单、带宽最省 | 100%（但难同步） |
| 归零制（RZ） | 正脉冲 = 1，负脉冲 = 0；每位中间回到零 | 提供同步参考 | 50%（带宽约为 NRZ 两倍） |

**编码效率例题**：10 Mb/s 曼彻斯特编码以太网，每码元携带 1/2 bit，码元速率 = 10 Mb/s ÷ 0.5 = **20 M 波特（MBd）**，所需带宽约为 NRZ 的两倍（NRZ 同速率只需 10 MBd）。

> **注意**：这里的"波特率 = 2×比特率"与多电平调制的"比特率 = 波特率 × log₂V"是两个独立机制，别混：多电平靠增加码元状态提速率，曼彻斯特系每个码元反而只带 1/2 bit。

### 5.2 调制：ASK / FSK / PSK / QAM

把数字数据搬到模拟载波上，靠改变载波的三个自由度（幅度、频率、相位）：

- **ASK 幅移**：改变幅度（0 无信号、1 有信号），抗噪最差，用于光纤通信；
- **FSK 频移**：改变频率，易实现、低速，用于低速无线/电话系统；
- **PSK 相移**：改变相位（0°/180°），抗噪较好，用于 Wi-Fi 等高速无线；
- **QAM 幅相联合**：同时改变幅度和相位，**星座点数 = 码元种类数 M，每码元 log₂M bit**（QAM-16 = 4 bit/码元），用于数字电视、Wi-Fi、有线通信。

QAM 的速率计算即 §4.4 例题 1 的套路：奈氏定波特率上限 → 乘每码元 log₂M 得比特率。

## 6. 一条链路传多路：信道复用

链路是昂贵的资源。复用要解决的问题是：**一条物理链路怎样同时承载多路信号**。五种复用，靠五种东西区分各路：

| 复用方式 | 靠什么区分各路 | 关键词 |
|---|---|---|
| **FDM 频分** | 不同频段，各路同时传 | **保护频带**防串扰；模拟主干 |
| **TDM 时分** | 固定时隙轮流传，时隙即身份 | 需同步、不带地址、怕突发 |
| **STDM 统计时分** | 按需动态分配时隙 | **必须带地址**、抗突发、利用率高 |
| **WDM 波分** | 不同光波长 | 本质是光纤上的 FDM |
| **CDM 码分** | 正交码片（码型） | 各路同频同时，靠码型分离（了解） |

- **FDM**：所有用户同时占用不同频段，频段之间要留保护频带防串扰，保护频带本身浪费带宽。
- **TDM（同步时分）**：所有用户轮流占用**全部频带**，时隙定长、需要同步；用户身份靠时隙位置识别，所以不带地址。
- **WDM**：在光纤上按波长（颜色）分光，本质就是光域的 FDM。
- **CDM**：各路同频同时发送，靠相互正交的码片序列区分（了解即可）。

### 6.1 TDM 的峰值拥塞

n 路用户复用一条 W 波特链路，每路固定分得 W/n。**即使所有用户平均速率之和 ≤ W，某用户瞬时峰值超过 W/n 时，其固定时隙装不下该速率的数据，依然会丢包/拥塞**。TDM 静态分配无法应对突发流量，这正是 STDM 存在的理由。

### 6.2 STDM：按需动态分配时隙

**统计时分复用（STDM）**：时隙不固定分配给用户，而是**按需动态分配**，有数据才占用时隙，并携带用户地址标识。

| 对比项 | TDM（同步时分） | STDM（统计时分） |
|---|---|---|
| 时隙分配 | 固定预分配 | 按需动态 |
| 空闲时隙 | 空转浪费 | 让给其他用户 |
| 是否带地址 | 不需要（时隙即身份） | **必须带地址** |
| 应对突发 | 差（峰值超份额即丢包） | 较好（动态借时隙） |
| 线路利用率 | 低 | 高 |

STDM 提高利用率的代价：时隙不固定，每个分组必须带地址信息；且同一用户突发峰值可能超过其平均份额，所有用户同时满发时仍需缓存。

> **注意两个经典设错点**：① "STDM 不需要地址信息"——反了，时隙不固定则**必须带地址**，TDM 才靠时隙位置识别用户；② "总平均速率不超链路带宽就不丢包"——TDM 下错，**峰值超份额照样丢**。

### 6.3 例题

链路 10 Mb/s，10 路用户平均 1 Mb/s、峰值 3 Mb/s：

- **TDM**：每路份额 = 1 Mb/s，峰值 3 > 1 → **丢包**；
- **STDM**：平均占用合计 10 Mb/s 恰满载，不丢包；但同时突发时仍需缓存。

## 7. 物理层设备：中继器与集线器

骨架最后一支是工作在物理层的设备。它们只认识信号、不认识帧，功能都是"让信号传得更远"。

| 设备 | 层次 | 做什么 | 局限 |
|---|---|---|---|
| 中继器 | 物理层 | 再生放大信号，延长网段 | 不识别帧，两端同协议同速率 |
| 集线器 | 物理层 | 多口中继：比特广播式转发 | 共享带宽、一个冲突域、半双工 |

- **中继器**：信号传远了会衰减失真，中继器把信号**再生（不是简单放大）**后转发到下一段，从而延长网段。两端网络必须**同协议、同速率**；5-4-3 规则（了解）。
- **集线器（Hub）**：相当于**多端口中继器**，任一端口收到比特，就向其他所有端口广播转发。因此所有端口**共享带宽、同属一个冲突域、只能半双工**。

> **注意**："集线器能隔离冲突域"是错的——Hub 全端口一个冲突域；隔离冲突域是交换机（链路层，见 [11 篇](/posts/872-net-11-link/)）。

### 8.1 传输介质与接口特性（了解）

- **物理层接口四大特性**：机械特性（接口形状、引脚数与排列、电缆类型）、电气特性（电压幅值、电流、速率与距离）、功能特性（各引脚的用途，如 Tx/Rx）、规程（过程）特性（信号时序、起止与同步过程）。名词对号即可，不深挖。
- **传输介质**：双绞线（绞合抗干扰）、同轴电缆、光纤（光的反射传信号，抗干扰强、速率高、距离远；多模 vs 单模）、无线。**以太网标准与介质的对应（10Base-T / 100Base-T 等）见 [11 篇 §8.2](/posts/872-net-11-link/)**（2025 已考 100Base-T 的介质）。
- **海明距离与码距**：纠错编码的基础名词，本篇只留名词；**差错控制/CRC 等完整内容在 [11 篇](/posts/872-net-11-link/)**。

## 8. 专题：卫星链路——高时延链路的典型场景

卫星链路不在骨架六支里，但它是物理层概念的综合应用：既考"时延四段"的定性辨析，又考利用率/窗口/序号位数的完整计算，是简答题和大题的中频考点。

### 9.1 卫星通信是什么

利用通信卫星作**空中微波中继**，地面站—卫星—地面站一跳直达，途中没有任何存储转发结点。

特点：

1. **覆盖范围广**：海洋、山区、荒漠、灾区都能通，不受地面地形与基站限制；
2. **频谱资源多、可用带宽大**；
3. **传播距离极远导致传播时延很大**：地球同步轨道（GEO）卫星距地面约 3.6 万 km，信号经"地面站→卫星→地面站"的**单程传播约 240 ms**（题目常取 250 ms），**往返 RTT 约 500 ms**。

### 9.2 卫星减少的是"存储转发时延"，不是传播时延

卫星链路省掉了中间路由器的存储转发，所以**排队时延与处理时延大幅减少甚至归零**（一段直达、无路由器排队）；但**传播时延反而急剧增大**（比地面链路多几百毫秒）。

这是"卫星通信减少了端到端哪类时延"的唯一正确答法，答"减少传播时延"是方向性错误。

**时延四段的取舍**：排队时延（最不确定）、处理时延（最小）、传播时延（距离决定）、传输时延（速率决定）。

- 地面长链路：中间结点多，存储转发累计的排队 + 处理时延大；
- 卫星链路：跳数少但距离远，排队 + 处理为零、传播时延极大。

两者是此消彼长的关系。

### 9.3 卫星通信 vs 地面蜂窝（4G/5G）

| 对比项 | 地面蜂窝（4G/5G） | 卫星通信 |
|---|---|---|
| 中继与时延 | 基站多跳存储转发，排队/处理时延不确定 | 空中一跳直达，基本无排队与处理时延 |
| 传播时延 | 小（亚毫秒） | **极大**（GEO 单向约 240 ms、RTT 约 500 ms） |
| 覆盖 | 跟基站走，有盲区 | 全球覆盖，含海洋/山区/灾区 |
| 容量与短板 | 密集区容量大、可网状扩容；依赖地面设施、灾害易断 | 频谱宽但单星容量有限；终端贵且耗电、交互体验差 |

卫星靠空中中继不依赖地面基站，终端密度低也能服务，适合宽带接入与应急通信；地面蜂窝在人口密集区的速率与容量远高于卫星。综合简答按"**广覆盖/不依赖地面设施/应急** vs **低时延/高容量/基站密集**"两侧对写即可。

### 9.4 利用率、窗口下限与序号位数计算

> **口径提醒**："窗口要多大"用的是**窗口下限 = 速率 × RTT**，属工程口径；教材的时延带宽积 = 带宽 × **单向**传播时延，是它的一半。判别表见 [01 篇 §3.5.1](/posts/872-net-01-overview/)。**考题若问"时延带宽积"，用单向传播时延，别把 RTT 套进去。**

**步骤**：

1. 单向传播时延 t_p（GEO 约 240 ms，题目一般直接给 250 ms）→ RTT = 2×t_p（忽略确认帧发送时延与处理时延；含确认帧 T_A 的完整式见 [01 篇 §3.7](/posts/872-net-01-overview/)）；
2. 单帧发送时延 T_D = 帧长 / 速率；
3. 停等协议利用率 **U = T_D / (T_D + RTT)**。RTT 远大于 T_D 时 U 趋近 0，这就是卫星链路必须开大窗口、不能用停等的原因；
4. 要 U ≥ 目标值 u（如 80%）：**W ≥ ⌈u·(T_D + RTT)/T_D⌉ = ⌈u·(1 + RTT/T_D)⌉**；只有问"**灌满管道**（U = 100%）"时才用 W ≥ ⌈(T_D + RTT)/T_D⌉ = 1 + ⌈RTT/T_D⌉；
5. 再用序号空间卡一道：**GBN 需 2ⁿ ≥ W + 1、SR 需 2ⁿ ≥ 2W**（[11 篇 §6.4](/posts/872-net-11-link/)）。

**例题**：卫星链路 128 kb/s，单向传播时延 250 ms，帧长 1000 B，不计确认帧开销。

T_D = 8000 bit / 128×10³ = 62.5 ms；RTT = 2×250 = 500 ms。

- 停等：U = 62.5 / (62.5 + 500) ≈ **11%**，远达不到 80%；
- 要 U ≥ 80%：W ≥ ⌈0.8 × (62.5 + 500)/62.5⌉ = ⌈0.8 × 9⌉ = ⌈7.2⌉ = **8 帧**；
- GBN 下需 2ⁿ ≥ 8 + 1 = 9：2³ = 8 < 9、2⁴ = 16 ≥ 9 → **帧序号至少 4 比特**。

**自检**：答案代回去 U = W·T_D/(T_D + RTT)：W = 8 时 8×62.5/562.5 ≈ **89%** ≥ 80% ✓；W = 7 时 ≈ 78%，差一点；W = 9 时 100%，那是"灌满管道"口径，不是 80% 门槛。

> **注意**：① 卫星是典型大传播时延链路，"时延小适合实时交互"是错的，交互类业务体验最差；② 停等协议 U = T_D/(T_D+RTT) 远小于 1，跑不满带宽，必须开大窗口；③ 算窗口时 RTT = 2× 单向传播时延（确认帧还要飞回来），别把单向时延当 RTT。

## 9. 最容易写错的十三处（速查清单）

1. 公式张冠李戴：无噪声用奈氏、有噪声用香农；奈氏还要分低通（2W）/带通（W），系数差一倍。
2. 忘换算 dB：30 dB = 1000 倍、3 dB ≈ 2 倍，不能把 30 直接当 S/N。
3. 两条件都给却只算一个：各算取 min，不能预设谁是瓶颈（§4.4 例题 2）。
4. 差分曼彻斯特把中间跳变当数据：中间只同步，数据看边界（有跳 = 0、无跳 = 1）。
5. "STDM 不需要地址"：反了，STDM 必须带地址，TDM 才靠时隙位置识别。
6. "总平均不超链路就不丢包"：TDM 下峰值超份额照样丢。
7. "集线器能隔离冲突域"：错，Hub 全端口一个冲突域；隔离靠交换机。
8. 波特率直接当比特率：多电平差一个 log₂V（QAM-16 是 4 bit/码元）；曼彻斯特系反过来，波特率是比特率的 2 倍。
9. 全双工以太网还算争用期：全双工无碰撞，CSMA/CD 不适用；半双工才有。
10. "卫星减少了传播时延"：方向反了，省的是排队 + 处理，传播时延反增（GEO 往返约 500 ms）。
11. "卫星时延小适合实时交互"：错，大传播时延链路交互体验最差。
12. 卫星用停等能跑满：错，U 远小于 1，必须开 W ≥ 1 + RTT/T_D 的大窗口。
13. 把单向传播时延当 RTT：RTT = 2× 单向；目标利用率乘 u，"灌满"才取 1 + RTT/T_D。
